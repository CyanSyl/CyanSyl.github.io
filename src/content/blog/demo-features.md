## 目录功能

如果屏幕够宽（窗口宽度大于 1024px），页面右侧会出现一个吸顶的「目录」栏，列出本文的所有二级、三级标题。滚动页面时，当前读到的章节会在目录里高亮；点击目录项可以平滑跳转到对应位置。

### 这是一个三级标题

三级标题在目录里会缩进一级显示，用来表示它隶属于上面的二级标题。

### 再来一个三级标题

多放几个标题，目录才有得看。

## 代码块与复制按钮

把鼠标悬停到下面的代码块上，右上角会浮现「复制」按钮，点一下代码就进剪贴板了：

```js
// 问候函数
function hello(name) {
  console.log(`你好，${name}！`);
}

hello('世界');
```

```python
def hello(name):
    print(f"你好，{name}！")

hello("世界")
```

行内代码 `const x = 1` 则没有复制按钮，样式也和代码块不同。

## 字数与阅读时长

标题下方那一行「全文 N 字 · 阅读约 M 分钟」是自动统计的：构建时去掉代码块和 Markdown 符号，中文字符按字计数，英文按单词计数，再按每分钟 400 字估算阅读时间。这段废话就是用来把字数撑上去的，不然统计结果太短看不出区别。多写几句，让数字更明显一些。

## 上下篇导航

把页面滚到最底部，会看到「上一篇（更新）」和「下一篇（更早）」两张卡片，点卡片直接跳到相邻文章。本文是目前最新的一篇，所以只会出现「下一篇（更早）」。
