# 前端语法笔记

记录学习过程中遇到的疑难点。每条包含：语法点、解释（结合后端背景类比）、示例。

## JS 基础语法

### 解构赋值
```js
const { title } = Astro.props;
```
从对象里把字段拆出来变成同名变量。类比 Java：`String title = props.getTitle();` 的缩写。

### 箭头函数 + map
```js
{posts.map((post) => <p>{post.title}</p>)}
```
- `.map()`：数组变换，对每个元素执行函数，返回新数组。类比 Java 的 `stream().map(...)`
- `(post) => ...`：箭头函数，即匿名函数 / lambda。Java 写 `post -> ...`，JS 写 `=>`

### await 异步等待
```js
const posts = await getCollection('blog');
```
等异步操作完成再往下执行，类比 Java 的 `future.get()`。`getCollection` 要读文件系统，是异步操作。

### import 模块导入
```js
import BaseLayout from '../layouts/BaseLayout.astro';
```
等价于 Java 的 `import`，但前端要写文件的相对路径。

## Astro 特有

### 两个"世界"：frontmatter vs `<script>`
`.astro` 文件顶部的 `---` 代码块在**构建时**运行（像服务端代码），浏览器看不到；文件里的 `<script>` 标签会发送到**浏览器**，在用户交互时执行。这是 Astro 的关键设计。

### 模板插值 `{ }`
HTML 里想嵌入 JS 表达式的结果，用花括号包起来，如 `<h1>{title}</h1>`。

## 浏览器 DOM 与事件

### 元素查找与操作
```js
const menu = document.querySelector('.menu');  // 用 CSS 选择器找元素
menu.getAttribute('aria-expanded');             // 读属性（返回值是字符串）
menu.setAttribute('aria-expanded', 'true');     // 写属性
```
`document` 是浏览器里整个页面（DOM 树）的入口对象。

### 可选链 `?.`
```js
menu?.addEventListener('click', () => { ... });
```
`menu` 为 `null` 时整句跳过、不报错。类似 Java 的 `Optional` / Groovy 的 `?.`。

### 事件监听
`addEventListener('click', 回调函数)`：元素被点击时执行回调。类比 Java 的 `setOnClickListener`。

### 严格相等 `===`
JS 的 `==` 会做隐式类型转换（`1 == '1'` 为 true），容易出 bug；**永远用 `===`**（值和类型都相同才为 true）。

### 模板字符串（反引号）
```js
`展开状态：${!isExpanded}`
```
反引号包裹的字符串里，`${}` 会被替换成变量值。类似 Java 的字符串格式化。
